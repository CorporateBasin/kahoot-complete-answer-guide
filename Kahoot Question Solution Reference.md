## 💡 O que é Kahoot?

**Kahoot!** é uma plataforma de aprendizado baseada em jogos, criada em 2012 na Noruega. Ela permite que professores, empresas e indivíduos criem questionários interativos que podem ser respondidos em tempo real por múltiplos participantes usando seus próprios dispositivos.

O formato de múltipla escolha com tempo limitado transforma o aprendizado em uma competição divertida, o que aumenta drasticamente o engajamento e a retenção de informações.

### Estrutura Básica

| Componente | Função |
|-----------|--------|
| 🎮 **Quiz** | Conjunto de perguntas |
| ⏱️ **Temporizador** | Limite de tempo por pergunta |
| 🏆 **Pontuação** | Baseada em velocidade e precisão |
| 📊 **Relatório** | Análise pós-jogo |
| 🎯 **Modos** | Clássico, Equipe, Desafio |

## ⚙️ Como Funciona

O Kahoot funciona com uma arquitetura cliente-servidor:

```
┌──────────────────────────────────────────┐
│  1. Host cria ou inicia um quiz          │
├──────────────────────────────────────────┤
│  2. Jogadores entram com código PIN      │
├──────────────────────────────────────────┤
│  3. Perguntas aparecem na tela principal │
├──────────────────────────────────────────┤
│  4. Jogadores respondem nos dispositivos │
├──────────────────────────────────────────┤
│  5. Pontuação é calculada em tempo real  │
├──────────────────────────────────────────┤
│  6. Ranking final é exibido              │
└──────────────────────────────────────────┘
```

### Sistema de Pontuação

| Fator | Peso |
|-------|------|
| ✅ Resposta correta | Base |
| ⚡ Velocidade | Bônus |
| 🔥 Sequência | Multiplicador |
| ❌ Resposta errada | 0 pontos |

## 🔧 Requisitos

### Para Responder

```
✅ Dispositivo: Smartphone, tablet ou computador
✅ Navegador: Chrome, Firefox, Safari ou Edge
✅ Conexão: Internet estável (mínimo 2 Mbps)
✅ Conta: Opcional para responder
✅ Aplicativo: Kahoot! app (opcional)
✅ Foco: Atenção total ao apresentador
```

### Para Criar

```
✅ Conta gratuita ou paga no Kahoot.com
✅ Navegador atualizado
✅ Criatividade para elaborar perguntas
✅ Banco de imagens (opcional)
✅ Internet estável
```
